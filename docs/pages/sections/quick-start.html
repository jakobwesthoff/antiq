Quick Start

git clone https://github.com/jakobwesthoff/antiq
cd antiq
cargo install --path .

Needs Rust 1.97 or newer. antiq push needs rsync 3.2.4 or newer.

Basic Usage

# Make the current directory a collection; every folder directly inside it is a piece
antiq init --pattern '*'

# Show what is idle, what would be archived, then archive it
antiq status
antiq archive -n
antiq archive

# Find a version by piece name or by the files it holds
antiq list scan
antiq grep 'main\.rs'

# Bring a version back as a folder, keeping the version
antiq fork scanner

# Mirror the collection to the target set in .antiq/config.toml
antiq push --init
