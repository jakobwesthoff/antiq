Quick Start

git clone https://github.com/jakobwesthoff/antiq
cd antiq
cargo install --path .

Needs Rust 1.97 or newer. antiq push needs rsync 3.2.4 or newer.

Basic Usage

# Make the current directory a collection of folders two levels down
antiq init --pattern '*/*'

# Show what is due, then archive it
antiq status
antiq archive

# Find a version by piece name or by the files it holds
antiq list scan
antiq grep 'main\.rs'

# Bring a version back as a folder
antiq unearth scan-old

# Mirror the collection to the target set in .antiq/config.toml
antiq push --init
