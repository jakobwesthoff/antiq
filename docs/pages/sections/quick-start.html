brew install jakobwesthoff/tap/antiq

Basic Usage

Make a collection Every folder directly inside becomes a piece. Details → 
antiq init --pattern '*'
Archive what is idle Look first, then archive. Details → 
antiq status
antiq archive -n
antiq archive
Find a version By the piece's name or by a file it held. Details → 
antiq list scan
antiq grep 'main\.rs'
Bring it back A working copy, the version stays archived. Details → 
antiq fork scanner
Mirror the collection To the target set in .antiq/config.toml. Details → 
antiq push --init
