Quick Start

cargo install antiq

Available on crates.io. antiq push needs rsync 3.2.4 or newer. 

brew install jakobwesthoff/tap/antiq

Available from jakobwesthoff/homebrew-tap. antiq push needs rsync 3.2.4 or newer.

Download pre-built binaries for macOS and Linux from GitHub Releases:

View Releases 
git clone https://github.com/jakobwesthoff/antiq
cd antiq
cargo install --path .

Needs Rust 1.97 or newer. antiq push needs rsync 3.2.4 or newer.

Basic Usage

# Make this directory a collection;
# each folder in it is a piece
antiq init --pattern '*'

# See what is idle, preview, archive
antiq status
antiq archive -n
antiq archive

# Find a version by name or by a file
antiq list scan
antiq grep 'main\.rs'

# Extract a working copy of a version
antiq fork scanner

# Mirror to the target in the config
antiq push --init
