Archives what went idle

A folder that nobody has touched for 30 days becomes a tar.zst version. antiq reads the archive back and compares it with the folder before it deletes the folder.

Finds without unpacking

antiq list and antiq grep search piece names and the paths of archived files from the listings, so nothing is unpacked to find a file.

Readable without antiq

Archives are tar.zst and listings are checksum lists that shasum -c reads. antiq push mirrors the collection to a folder or an ssh target as plain files with rsync.
