# 10. Name the project antiq

Date: 2026-11-02

## Status

Accepted

## Context

The working name timecapsule cannot become the crate name, because
`timecapsule` is taken on crates.io. The name also becomes the command
users type. It has to be free on crates.io, must not be an existing
command-line tool, and must not carry an odd meaning in a web search.

## Decision

The project, the crate and the binary are named antiq: "antique" spelled
with a q.

## Consequences

The marker directory of a managed folder is `.antiq/`. Command names and
the noun for a managed folder are chosen to fit the name.
