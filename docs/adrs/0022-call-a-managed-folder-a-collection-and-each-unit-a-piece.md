# 22. Call a managed folder a collection and each unit a piece

Date: 2026-11-03

## Status

Accepted

## Context

Help texts, messages and documentation need words for a managed folder
and for the units in it. Because units are selected by patterns, not
every folder inside a managed folder is a unit.

## Decision

A managed folder is called a collection. A unit is called a piece.
"Folder" keeps its plain meaning of a directory on disk.

## Consequences

None further.
