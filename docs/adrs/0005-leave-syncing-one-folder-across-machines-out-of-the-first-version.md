# 5. Leave syncing one folder across machines out of the first version

Date: 2026-11-02

## Status

Accepted

## Context

The playground exists on more than one machine. `timecapsule-sync.sh`
mirrors each machine into a directory of its own on the NAS.

## Decision

The first version does not sync one managed folder between machines.
The design leaves room to add it later.

## Consequences

_Not yet established._
